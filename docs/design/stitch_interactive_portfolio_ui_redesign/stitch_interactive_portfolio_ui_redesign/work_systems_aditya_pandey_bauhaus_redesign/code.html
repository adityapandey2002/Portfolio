FOUR DETERMINISTIC GUARANTEES FOR LOW-RESOURCE COMPUTING

P1

Offline-First By Default

No patient, doctor, or nurse midwife should ever be blocked by 2G/EDGE network dropouts. Client mutations serialize to IndexedDB first and flush asynchronously.

P2

Cryptographic Audit Logs

Financial checkouts and healthcare clinical metrics are append-only. Each mutation receives SHA-256 validation timestamps before reaching central servers.

P3

Deterministic Budgets

Strict sub-2.5s LCP on throttled 3G connections. Micro-bundles (<170kB gzip) ensure budget Android devices render without crashing browser tabs.

P4

Field-Hardened Ergonomics

High-contrast visual design engineered for extreme glare in direct Bihar sunlight (44°C summers). Bilingual UI strings with zero reliance on ambiguous iconography.
